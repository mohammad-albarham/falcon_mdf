falcon_mdf browser viewer

GitHub crates.io docs.rs

ASAM MDF v4 (.mf4) decoded entirely in your browser — nothing is uploaded, the file never leaves your machine. Parsing and decoding run in a worker; zoom levels are decimated in Rust, so the page never freezes.

Drop an .mf4 file here or click to browse

    wheel: zoom · drag: pan · shift-drag: zoom to region · click: cursor A · shift-click: cursor B (region stats; Esc clears) · double-click: reset · move the pointer for a cursor readout · click channels to plot (up to 8) · Overlay/Stacked: one pane vs one lane per channel · Relative/Absolute: seconds from start vs wall-clock X labels · keyboard (click the plot to focus): ←/→ pan · +/− zoom · Home reset · 1–8 toggle plotted channel N · touch: drag pans, pinch zooms · click a legend entry to select it
    Powered by falcon_mdf compiled to WebAssembly. This binding reads MDF v4; v3 files are not supported.
